# Tefsir Kütüphanesi — sürüm bilgisi

Bu depoda yalnız `surum.json` bulunur. Tefsir Kütüphanesi programı, açılışta (günde en çok bir kez) bu dosyayı okuyarak yeni bir sürüm çıkıp çıkmadığına bakar ve çıktıysa yeniliklerini gösterir. Program hiçbir şey indirmez ve kurmaz.

```json
{"version": "4.14", "date": "…", "notes": ["…"], "url": "https://… (isteğe bağlı: indirme sayfası)"}
```
